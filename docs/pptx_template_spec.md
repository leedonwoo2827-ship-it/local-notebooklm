# 📐 회사 PPTX 양식 작성 가이드

본 문서는 **회사 디자인팀(사업자측)** 이 Local NotebookLM 의 슬라이드 산출물에 적용할
PPTX 마스터 양식을 만들 때 따라야 하는 사양을 정의한다.

> 양식이 완성되면 **`assets/pptx_template.pptx`** 경로에 그대로 두면 자동 적용된다.
> (또는 `.env` 의 `PPTX_TEMPLATE_PATH` 변수로 다른 경로 지정 가능)

---

## 1. 파일 형식

| 항목 | 값 |
|---|---|
| 파일 확장자 | `.pptx` (PowerPoint 2007 이상) |
| 슬라이드 크기 | **16:9 (33.867 × 19.05 cm 또는 13.333 × 7.5 in)** ← 반드시 |
| 슬라이드 비율 | 와이드 (Widescreen) |
| 파일명 | `pptx_template.pptx` |
| 위치 | `assets/pptx_template.pptx` |

---

## 2. 슬라이드 마스터(필수)

회사 디자인 룰을 슬라이드 마스터에 박아두면 우리 코드가 그 위에 콘텐츠를 얹는다.
**다음 두 가지 레이아웃**이 마스터에 정의되어 있어야 한다:

### 2.1 표지 레이아웃 (Layout #0)

PowerPoint의 "제목 슬라이드"에 해당. 다음 placeholder 두 개 필수:

| Placeholder | 용도 | 자리 |
|---|---|---|
| Title 1 | 발표 제목 (예: "부동산 FP 핵심 개념 총정리") | 가로 중앙, 본문 영역 안 |
| Subtitle 2 | 부제목 (예: "법률·경제·물리적 측면부터 공시가격·LTV까지") | 제목 바로 아래 |

> 로고/배경 이미지가 있으면 마스터 자체에 박아주시면 됩니다. 우리 코드는 건드리지 않습니다.

### 2.2 본문 레이아웃 (Layout #1)

"제목+내용" 슬라이드. 다음 placeholder 두 개 필수:

| Placeholder | 용도 |
|---|---|
| Title 1 | 슬라이드 제목 (1줄) |
| Content/Body 2 | 본문 영역 — 우리 코드가 **불릿 3~5개**를 채워넣는다 |

본문 영역은 텍스트박스/Content placeholder 어느 쪽이든 OK. 단, **다단(columns)이 아닌 단일 영역**.

> 페이지 번호(슬라이드 번호)와 푸터(회사명/날짜)는 마스터의 placeholder 로 두면 자동 표시됩니다.

---

## 3. 색상 권장

마스터에 정의된 색을 우리 코드가 덮어쓰지 않습니다(다만 강조 바 두 곳만 코드 색상 사용 — 변경 원하시면 별도 요청). 회사 BI 컬러를 자유롭게 사용해 주세요.

만약 우리 코드의 기본 강조 색을 회사 컬러로 통일하고 싶으시면 알려주세요. 다음 두 값만 바꾸면 됩니다:
- `accent` (포인트 컬러) — 현재 `#2E5BFF` (블루)
- `bg_title` (표지 배경) — 현재 `#1F2A44` (네이비)

---

## 4. 폰트

마스터에서 사용한 한글/영문 폰트가 적용됩니다. **`맑은 고딕` 또는 `Pretendard` 권장** (Windows·macOS 모두 자연스러움). 디자인팀이 별도 사내 폰트 사용 시:
- 폰트 파일이 시청측 PC에 깔려있어야 표시됨
- 또는 PPTX 저장 시 **"파일에 글꼴 포함"** 옵션 체크

---

## 5. 양식 검증 체크리스트

양식 완성 후 디자인팀에서 확인할 것:

- [ ] `assets/pptx_template.pptx` 로 저장됨
- [ ] 16:9 와이드 비율
- [ ] 표지 레이아웃에 Title + Subtitle placeholder 2개
- [ ] 본문 레이아웃에 Title + Content placeholder 2개
- [ ] PowerPoint 에서 양식 열어 "새 슬라이드" 시 위 두 레이아웃이 자동 노출됨
- [ ] (선택) 페이지 번호·푸터·로고가 마스터에 박혀있음

---

## 6. 적용 방법 (개발자/사용자 측)

양식 파일을 받으면:
1. `d:\00work\260519-localnotebooklm\assets\pptx_template.pptx` 위치에 저장
2. Local NotebookLM 앱을 재시작
3. Studio → 🎴 슬라이드 자료(PPTX) 클릭 → 양식 자동 적용된 PPTX 다운로드

양식 파일이 없으면 코드 내장 기본 테마(네이비/블루)가 사용됩니다.

## 7. 향후 확장 (참고)

다음 기능은 양식 단계가 안정되면 후속으로 추가 검토:
- 노트북별 다른 양식 사용 (해외사업 AIM 용 / 사내 보고용 / 마케팅용)
- 양식 내 차트/표 placeholder 매핑
- 양식 내 슬라이드 마스터 색상을 자동 추출해 카드뉴스 HTML 색감과 통일
