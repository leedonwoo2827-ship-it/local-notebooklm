# 🧰 사내 활용 시나리오

회사에서 Local NotebookLM 을 실제로 어떻게 쓰면 가장 좋은지에 대한 예시 모음.
직원 1인 1노트북 단위로, **소스 → 채팅 → 산출물** 의 3단계 흐름을 따른다.

> 모든 산출물은 `data/notebooks/<노트북 이름>/artifacts/` 에 영구 저장됩니다.
> 우측 Studio 패널의 「생성된 메모」 영역에 앱 재시작 후에도 그대로 표시되며,
> 다운로드 가능한 파일은 헤더에 `⬇` 마커가 붙습니다. 좌측 `🗑` 두 번 클릭으로
> 개별 산출물을 영구 삭제할 수 있습니다.

---

## 1. 강의 자막 → 카드뉴스 + 보고서 + 교안

**상황**: 사내 교육 영상 자막(SRT/VTT) 3개를 받음. 교육 자료로 정리 필요.

1. 새 노트북 생성 (예: `260520-부동산교육`)
2. 자막 3개를 좌측 「+ 소스 추가」 에 드래그
   - 인덱싱 자동 진행 (자막 1개당 약 30~60초)
3. 우측 Studio →
   - **🖼 카드뉴스** → 회차별 PNG + 종합 PNG 자동 생성 (SNS/메신저 용)
   - **📄 HWPX 보고서** → 강의 전체 종합 보고서 `.hwpx` 다운로드
   - **📊 PPTX 보고서** → 발표용 6장 슬라이드 `.pptx`
   - **📋 슬라이드 교안(텍스트)** → 강의용 20장 분량 `.md` — NotebookLM·ChatGPT·Gemini Canvas 에 붙여넣어 예시 추가/재구성/번역 등 추가 가공
   - **❓ 퀴즈** → 객관식 4지선다 `.xlsx` (자가시험·교육 후 평가용)
   - **🗂 플래시카드** → Anki `.apkg` + 검토용 `.xlsx`

**소요**: 약 3~5분 (인덱싱 포함)

> ⚠️ **자막을 한꺼번에 너무 많이 올리지 말 것.** 사내 LiteLLM 프록시는 업스트림
> 호출 타임아웃이 60초로 고정돼 있다. 슬라이드 교안(20장)·HWPX 보고서 같이
> 한 번의 큰 LLM 호출로 처리하는 산출물은, 자막을 통째로 합쳐 보내면 60초를
> 넘겨 **408 Timeout** 으로 떨어진다. **자막은 1~2개씩 노트북당 분산**하거나,
> 채팅으로 먼저 핵심을 추려둔 뒤 산출물을 만드는 게 안전하다.

## 2. 통신연수 책 1개 장 → 학습평가 + 슬라이드 교안 + 플래시카드

**상황**: 종이책 1권을 통째로가 아니라 **1개 장씩** 학습 자료화. 본문 텍스트
(약 20쪽)를 입력해, 책 끝에 붙은 「단원학습정리 + 학습평가 + 정답해설」(약 8쪽)
같은 산출물을 자동으로 만들어 학습/시험 준비에 활용.

**입력 예시**: `_assests/input_16-43.pdf` ─ "MZ에서 시니어까지 세대공감 금융솔루션 3"
제1장 시니어 고객 특성과 설계 전략 (본문 20쪽, 약 1.5만 토큰)

**기대 산출물 형태**: `_assests/OUTPUT_44-51.pdf` ─ 같은 책의 단원학습정리 8쪽
(요약 표 + 핵심 정리 5항목 + 4지선다 5문항 + ○✕ 1문항 + 정답해설)

1. 새 노트북 생성 (예: `261020-시니어금융솔루션-1장`)
   - **책 1권을 한 노트북에 다 넣지 말 것**. 1장 = 1노트북이 가장 깔끔하다.
2. 본문 텍스트 업로드 (`.pdf` / `.txt` / `.md` 모두 가능)
   - PDF 라면 텍스트 추출이 되는 본 (스캔 PDF 는 OCR 별도 필요)
3. 우측 Studio 순서 (OUTPUT_44-51 스타일에 맞춰):
   - **❓ 퀴즈** → 4지선다 5문항 + 정답·해설 `.xlsx` (학습평가에 1:1 대응)
   - **📋 슬라이드 교안(텍스트)** → 6~10장으로 슬라이드 수를 줄여 생성
     (디폴트 20장은 1개 장 분량엔 과함). 단원학습정리·핵심 정리·학습목표 부분에 대응.
   - **🗂 플래시카드** → 책의 핵심 용어/정의를 Anki 카드로 → 시험 직전 반복 학습
4. (선택) 채팅창 활용:
   - "1장의 학습목표 5개를 한 문장씩으로 추려줘"
   - "은퇴 준비기 vs 초기 은퇴기 vs 후기 고령기 핵심 차이를 표로"
   - "이 장에서 시험에 나올 가능성이 가장 높은 5개 포인트"

**소요**: 약 2~3분 (책 1장 ≈ 1.5만 토큰, 자막 1시간보다 가볍다)

**팁**:
- 학습평가 문항 수를 늘리고 싶으면 [prompts/quiz_ko.md](../prompts/quiz_ko.md) 의
  N 값을 키운다 (10문항·15문항 등).
- 같은 책의 다음 장은 **새 노트북** 으로. 노트북 인덱스가 섞이지 않아 시험 직전
  복습 시 챕터별로 깨끗이 분리된다.

## 3. PDF 보고서 → 마인드맵 + 요약

**상황**: 거래처 제안서 PDF 1권. 빠르게 핵심만 파악하고 회의 준비.

1. 새 노트북 생성 (예: `거래처-제안서-검토`)
2. PDF 업로드 (텍스트 추출 가능본 — 스캔본은 미지원)
3. 우측 Studio →
   - **마인드맵** 클릭 → 계층 구조 한눈에
   - **HWPX 보고서** 클릭 → 회의 자료용 정리본
4. 채팅창에서 추가 질의: "예산 항목만 표로 정리해줘"

**팁**: 한 노트북에 여러 거래처 PDF 를 같이 올리면 비교 분석도 가능.

---

## 4. 회의록(MP4) → 액션 아이템 추출

**상황**: 회의 녹화본 1시간짜리 MP4. 회의록 + 액션 아이템 필요.

1. 새 노트북 생성
2. MP4 업로드 → faster-whisper 가 자동 STT (CPU 기준 ~3분 / GPU 기준 ~30초)
3. 채팅창:
   - "회의록을 시간순으로 정리해줘"
   - "결정 사항만 목록으로"
   - "각 참석자가 맡기로 한 액션 아이템을 담당자별로 정리"
4. Studio → **HWPX 보고서** → 회의록 `.hwpx` 다운로드

**프록시 권장**: STT 가 느리면 `.env` 의 `WHISPER_BACKEND=litellm` 로 변경 →
회사 LiteLLM 으로 위임 (CPU PC 부담 0, ~30초).

---

## 5. 자료 조사 (여러 PDF/문서 묶음) → 플래시카드 + 퀴즈

**상황**: 자격증/시험 준비. 강의 자료, 기출, 요약본을 묶어 학습.

1. 새 노트북 생성 (예: `자격증-2026Q3`)
2. 자료 5~10개 업로드 (PDF/Docx/TXT 혼합 가능)
3. Studio →
   - **플래시카드** 클릭 → Anki 형식 `.apkg` 다운로드 → Anki 앱으로 학습
   - **퀴즈** 클릭 → 객관식 자동 생성 (정답·해설 접힘 박스 포함)
4. 채팅창: "지난 3년간 기출에 반복된 주제 5가지 알려줘"

**Anki 사용법**: `.apkg` 다운로드 → Anki 데스크톱 → 파일 → 가져오기

## 6. 사내 정책/규정 문서 → 정책 Q&A 봇

**상황**: 인사규정·복지정책·출장규정 PDF 모음. 직원 질의에 즉답.

1. 노트북 1개에 모든 정책 PDF 묶음
2. 채팅창에서 직접 질의:
   - "출장비 일일 한도가 얼마야?"
   - "재택근무 신청 절차 단계별로"
   - "연차 이월 가능한 일수 한도"
3. 답변에 출처 표시 자동 첨부 — `[인사규정.pdf p.12]`

**팁**: 정책 개정 시 새 노트북을 만들지 말고 같은 노트북에 신규 PDF 만 추가.
이전 KG 는 그대로 유지되고 신규 내용만 추가 인덱싱됨.

---

## 7. 영업 자료 (해외사업 AIM) → 카드뉴스 + PPTX

**상황**: 해외 거래처에 제안할 자료. 본사 자료를 영업용으로 압축.

1. 본사 자료 모두 업로드
2. Studio →
   - **🖼 카드뉴스** → SNS/이메일 첨부용 PNG (1080×자동 높이)
   - **📊 PPTX 보고서** → 회사 양식 적용된 발표용 `.pptx`
3. 카드뉴스 PNG 는 그대로 메일·메신저 사용, PPTX 는 발표용

**회사 양식 적용**: `assets/pptx_template.pptx` 에 회사 마스터를 두면 자동 적용.
가이드는 [docs/pptx_template_spec.md](pptx_template_spec.md) 참고.

## 운영 팁

### 현재 모델 매핑 (기본값)

배포 시점의 `.env` 가 다음과 같이 박혀 있다. 「전부 DeepSeek」 통일이 아닌,
용도별 분리:

| 프로파일 | 모델 | 역할 |
|---|---|---|
| `MODEL_CHAT` | `deepseek-v4-flash` | 채팅·일반 Q&A (저렴 + 1M 컨텍스트) |
| `MODEL_EXTRACT` | `gpt-5.4-mini` | 인덱싱 entity 추출 (JSON schema 필요) |
| `MODEL_STRONG` | `claude-sonnet-4-6` | 보고서·심층 Q&A (한국어 품질) |
| `MODEL_CREATIVE` | `claude-sonnet-4-6` | Studio 창작물 (슬라이드·카드뉴스·교안) |

비용·다른 조합 변경은 [docs/pricing.md](pricing.md) 참고.

### 60초 천장 주의 (중요)

사내 LiteLLM 프록시는 업스트림 호출 타임아웃이 **60초로 고정**돼 있다. 한 번의
LLM 호출로 끝나는 산출물(슬라이드 교안 20장, HWPX 보고서 1장, 큰 PPTX 등) 에서
입력 + 출력 합이 약 **5만 토큰 이상** 으로 커지면 60초 안에 못 끝나고 `408 Timeout`
으로 떨어진다. 폴백 모델로 재시도되더라도 같은 60초가 다시 걸려 결국 실패한다.

**예방**:
- 자막은 1~2개씩 노트북에 분산. 책은 1장(약 20쪽) 단위.
- 큰 입력이 필요한 경우 채팅으로 먼저 압축하고, 그 결과를 가공.
- 슬라이드 교안 장수는 콘텐츠 분량에 맞춰 — 책 1장이면 6~10장, 자막 3개면 20장.

### 노트북을 언제 새로 만들고 언제 같이 두나
- **새로 만들어야**: 주제·문서군이 완전히 다를 때 (사업 부서 다름, 도메인 다름,
  같은 책의 다른 장)
- **같이 둬야**: 같은 주제의 여러 자료 (시리즈 강의, 같은 프로젝트의 회의록 묶음,
  같은 정책의 여러 버전)

### 산출물 영구 저장 + 정리
- 좋은 산출물만 남기고 나머지는 좌측 `🗑` 두 번 클릭으로 정리
- 파일은 `data/notebooks/<이름>/artifacts/<산출물>/` 디렉토리에 저장돼 있어서
  탐색기로 직접 가져가는 것도 가능

### 보안
- API 키는 PC 의 `.env` 에만 저장. 클라우드 미전송.
- 임베딩(BGE-M3)·STT(faster-whisper)·인덱스 모두 로컬.
- 외부로 나가는 건 LLM 호출 본문(LiteLLM 프록시) 뿐.
- VPS 이전 가능 — `.env` 의 `WHISPER_BACKEND` 만 토글하면 GPU 없는 환경에서도
  동일 코드 동작.
