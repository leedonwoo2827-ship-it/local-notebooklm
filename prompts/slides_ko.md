# 슬라이드 자료(=카드뉴스) 프롬프트

다음 자막/텍스트로부터 {{N}}장의 카드뉴스 슬라이드를 만들어라.

전제:
- 타임코드는 이미 제거되었다고 가정한다.
- 한국어로 작성.
- 시각화 의도를 image_hint로 남겨라(이후 이미지 생성 단계에서 사용).

출력은 **JSON만**. 펜스 없이, 추가 설명 없이.

스키마:
```
{
  "slides": [
    {
      "title": "1줄 제목 (15자 이내)",
      "body": "2~3문장 핵심 요약. SNS 배포용 톤.",
      "keywords": ["핵심키워드1", "핵심키워드2", "핵심키워드3"],
      "image_hint": "구체적인 비주얼 묘사 한 줄"
    }
  ]
}
```

내용 규칙:
- 1번 슬라이드는 표지 역할(주제 + 한 줄 후크).
- 중간 슬라이드는 핵심 개념·예시·수치.
- 마지막 슬라이드는 정리/CTA.
- 같은 키워드 반복 금지, 슬라이드 간 의미 중복 금지.
- 사실 진술은 자막에 근거하라. 자막에 없는 정보 생성 금지.
