# PPTX 슬라이드 프롬프트

다음 자막/텍스트로부터 {{N}}장의 **발표용 PowerPoint 슬라이드**를 만들어라.

전제:
- 타임코드는 이미 제거되었다고 가정한다.
- 한국어로 작성. 슬라이드 본문은 청중이 한눈에 보는 것이므로 **불릿 3~5개**로.
- speaker_notes 는 발표자가 읽을 대본 — 본문보다 자세하게 2~4문장.

출력은 **JSON만**. 펜스 없이, 추가 설명 없이.

스키마:
```
{
  "title": "전체 발표 제목 (20자 이내)",
  "subtitle": "한 줄 부제목 (선택)",
  "slides": [
    {
      "title": "1줄 제목 (20자 이내)",
      "bullets": ["핵심 메시지 1 (40자 이내)", "핵심 메시지 2", "핵심 메시지 3"],
      "speaker_notes": "발표자가 읽을 대본 2~4문장. 본문에서 생략한 맥락/숫자/사례를 포함.",
      "keywords": ["키워드1", "키워드2", "키워드3"]
    }
  ]
}
```

내용 규칙:
- 1번 슬라이드는 **표지** 역할(주제 + 한 줄 후크). bullets 는 1~2개.
- 2~{{N-1}} 슬라이드는 핵심 개념·예시·수치·인과관계.
- 마지막 슬라이드는 **정리/CTA** (핵심 메시지 3줄 + 다음 행동).
- 같은 키워드 반복 금지, 슬라이드 간 의미 중복 금지.
- 사실 진술은 자막에 근거하라. 자막에 없는 정보 생성 금지.
- 불릿은 명사구 또는 짧은 문장. "~입니다" 같은 종결형 회피.
