# 슬라이드 교안(텍스트) 프롬프트

다음 자료(자막/대본/문서)로부터 {{N}}장의 **강의 교안용 슬라이드 텍스트**를 만들어라.

전제:
- 타임코드는 이미 제거되었다고 가정한다.
- 한국어로 작성. 청중은 학습자/수강생이며, 발표용 한 줄 핵심이 아니라 **수업에서 따라 읽으며 학습할 수 있는 분량**으로 작성한다.
- 이 산출물은 NotebookLM / ChatGPT / Gemini Canvas 등 외부 도구에 그대로 붙여넣어 추가 가공(예시 추가·재구성·번역) 할 재료다. 따라서 슬라이드 간 흐름과 키워드 일관성을 유지한다.

출력은 **JSON만**. 펜스 없이, 추가 설명 없이.

스키마:
```
{
  "title": "강의 전체 제목 (30자 이내)",
  "subtitle": "한 줄 부제목 — 학습 목표 위주 (선택)",
  "slides": [
    {
      "title": "1줄 제목 (25자 이내)",
      "bullets": ["핵심 내용 1 (60자 이내, 사실/정의/예시 위주)", "핵심 내용 2", "핵심 내용 3", "핵심 내용 4"],
      "speaker_notes": "강사가 보충 설명할 내용 3~5문장. 예시·이유·연결 개념·실수 포인트를 담아 학습자가 혼자 읽어도 이해되도록 작성.",
      "keywords": ["키워드1", "키워드2", "키워드3"]
    }
  ]
}
```

내용 규칙:
- 1번 슬라이드는 **강의 개요** — 학습 목표 3~5개 + 전체 흐름 한 줄.
- 2번 슬라이드는 **선수 지식 / 용어 정의**.
- 3~{{N-2}} 슬라이드는 핵심 개념을 한 번에 한 가지씩 깊이 있게 — 정의 → 예시 → 자주 하는 오해/실수.
- {{N-1}} 슬라이드는 **종합 정리 / 도식**.
- 마지막 슬라이드는 **연습 문제 또는 확인 질문 3~5개**.
- bullets 는 4개 안팎으로 발표용보다 정보량이 많아도 됨 (학습자가 읽으며 따라가는 구조).
- 사실 진술은 입력 자료에 근거하라. 자료에 없는 정보는 생성 금지.
- 같은 키워드의 반복 사용은 피하고, 슬라이드 간 의미 중복 없게 흐름을 짠다.
- 종결형(`~입니다`) 회피. 명사구 또는 간결 평서문.
