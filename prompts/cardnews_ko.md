# 카드뉴스(인포그래픽) 프롬프트

다음 자막/텍스트로부터 **한 장의 인포그래픽 카드뉴스**에 들어갈 콘텐츠를 만들어라.

전제:
- 한국어로 작성, SNS/사내 공유용 톤.
- 결과 JSON 만 출력 (펜스/설명 금지).
- 본 콘텐츠는 HTML 템플릿에 채워져 1080×1620(세로 카드) 이미지로 렌더링된다.
- 사실 진술은 자막에 근거하라. 자막에 없는 정보 생성 금지.

스키마:
```
{
  "headline": "카드뉴스 메인 제목 (20자 이내, 한 줄)",
  "subhead":  "한 줄 부제 (40자 이내) — 메인 메시지 요약",
  "hero_icon": "표지 영역에 어울리는 이모지 1개",
  "sections": [
    {
      "icon":  "이 섹션을 대표하는 이모지 1개",
      "title": "섹션 제목 (12자 이내)",
      "body":  "1~2문장 설명 (60자 이내). 명사구 또는 짧은 문장.",
      "tags":  ["키워드1", "키워드2"]
    }
  ],
  "summary_bar": {
    "label": "한눈에 보는 핵심 (예: '한눈에 보는 미래 모습')",
    "pills": [
      {"icon": "이모지", "text": "한 줄 요약 (15자 이내)"}
    ]
  },
  "footer": "출처/시리즈명/날짜 같은 한 줄 캡션 (선택)"
}
```

구성 규칙:
- `sections` 는 **정확히 6개**.
- 1번 섹션은 도입(전체 요약/정의), 2~5번은 핵심 개념·예시·수치, 6번은 정리/시사점.
- 각 섹션 `title` 은 서로 다른 주제. 중복/유사 표현 금지.
- `summary_bar.pills` 는 **정확히 5개** — 카드 하단 띠에 표시되는 핵심 키 메시지.
- 이모지는 의미가 명확한 것 선택 (예: 메모리=🧠, 도구=🛠️, 검색=🔍, 검증=✅, 자동화=⚙️, 미래=🚀).
- 본문은 **격식체 회피** — "~한다", "~된다" 같은 종결 사용. "~입니다" 금지.
