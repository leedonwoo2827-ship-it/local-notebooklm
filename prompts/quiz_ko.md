# 퀴즈 프롬프트

노트북 핵심에서 4지선다 객관식 문항 {{N}}개를 출제하라.

규칙:
- 한국어
- 정답이 명확한 사실 기반 문항만
- 보기 4개 모두 그럴듯해야 함(매력적 오답)
- answer는 1~4 정수
- rationale은 정답 이유 + 오답 함정 짧게
- 같은 개념 중복 금지
- 출력은 **JSON만**, 펜스/설명 없이

스키마:
```
{
  "questions": [
    {
      "question": "문항 텍스트",
      "choices": ["보기1", "보기2", "보기3", "보기4"],
      "answer": 2,
      "rationale": "정답 이유 + 오답 함정 한 줄"
    }
  ]
}
```
