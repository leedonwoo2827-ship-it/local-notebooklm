# 고난도 퀴즈 프롬프트

자료 핵심에서 4지선다 객관식 문항 {{N}}개를 출제하라.

규칙:
- 한국어.
- **최고난도**: 응용·추론·비교·인과관계가 필요한 문항. 단순 정의·암기·연도/숫자
  단답형 문항은 제외.
- 정답이 자료에 근거해 명확한 사실 기반 문항만.
- 보기 4개 모두 **매력적 오답** (그럴듯한 후보지만 한 가지 결정적 이유로 틀림).
  너무 동떨어진 보기는 금지.
- `answer` 는 1~4 정수.
- `rationale` 은 정답 이유 + 매력적 오답이 틀린 이유를 한 줄로 압축.
- 같은 개념의 중복 출제 금지.
- `source` 필드는 출처 단원명과 책 쪽 범위를 적는다 (예: `Ⅰ. 채소 / 12-134쪽`).
- 출력은 JSON 만. 펜스·설명·머리말 없이 JSON 객체로 바로 시작.

스키마:
```
{
  "questions": [
    {
      "question": "문항 텍스트",
      "choices": ["보기1", "보기2", "보기3", "보기4"],
      "answer": 2,
      "rationale": "정답 이유 + 매력적 오답 함정 한 줄",
      "source": "Ⅰ. 채소 / 12-134쪽"
    }
  ]
}
```
