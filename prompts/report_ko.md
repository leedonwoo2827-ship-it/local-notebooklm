# 보고서 생성 프롬프트

업로드된 노트북 전체 소스를 종합해 약 3,000자 분량의 Markdown 보고서를 한국어로 작성하라.

초점: {{FOCUS}}

구조(헤더 고정):
1. `## 요약` — 3~5문장 핵심 요약
2. `## 배경` — 다루는 주제·맥락
3. `## 핵심 내용` — 3~7개 하위 섹션, 각 섹션 200~400자
4. `## 시사점` — 실무·후속 연구·적용 포인트
5. `## 인용` — 본문에서 사용된 모든 출처 목록 `[소스명 p.쪽]`

작성 규칙:
- 본문 모든 단정문에 `[소스명 p.쪽]` 인용을 본문 안에 박는다.
- 소스에 없는 추론은 "추정:"으로 명시한다.
- 표가 필요하면 Markdown 표 사용.
- 결론에서 새 정보 도입 금지.
